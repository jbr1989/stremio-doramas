## 2026-10-22 - Pre-indexed lookup maps for genre mapping and pre-compiled regexes
**Learning:** Performing repeated O(N) array scans (`Array.prototype.find`, `filter`, `map`) inside core request handlers (such as genre mapping per item/catalog) introduces unnecessary execution overhead in high-throughput Workers. Pre-indexing static metadata into JavaScript `Map` objects at module load time provides ~2.5x faster O(1) lookups. Additionally, short-circuiting regex execution when no special entity characters (`&`) exist in strings prevents unnecessary RegExp engine invocations during title cleaning.
**Action:** Always pre-compute static metadata into `Map` lookups and check string triggers (e.g. `s.includes("&")`) before invoking heavy regex operations in text transformation routines.
